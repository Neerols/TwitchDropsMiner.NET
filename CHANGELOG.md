# История изменений

## v1.3.0 — 09.10.2026

Исправления по итогам ревью кода и теста.

### Исправлено
- **Бесконечный цикл входа после выхода или истечения токена**: при выходе и при отклонённом токене сессия удаляется и из встроенного браузера. Войти под другим аккаунтом теперь тоже можно.
- Выход удаляет локальные данные входа, даже если Twitch не ответил на запрос отзыва токена.
- **Integrity-токен**: одновременные запросы ждут одну общую попытку, после неудачи пауза 10 минут. Раньше каждый GQL-запрос мог ждать по 60 секунд.
- **Реальный прогресс с сайта выставляется каждому дропу отдельно**: минуты больше не «откатываются» у кампаний с цепочками дропов.
- **Плеер под надзором**: один плеер даже при быстрой смене канала, восстановление после падения процесса или если видео не играет 3 минуты, плановая перезагрузка раз в 3 часа. Отключение настройки «Встроенный плеер» сразу останавливает его.
- Служебные запросы (integrity, прогресс) идут через один постоянный скрытый браузер и завершаются по первому ответу, а не открывают новое окно каждые 5 минут.
- Утечка памяти в websocket: ожидание больше не создаётся каждую секунду.
- Убраны запросы видеосегментов (HLS): теперь засчитывает плеер, а эти запросы могли подвешивать цикл просмотра при сбоях CDN.
- Перезапуск (вход в другой аккаунт, выход) больше не теряется, если совпал с загрузкой кампаний.
- Ошибка записи `settings.json` больше не вызывает перезапуск майнера.
- Перенос данных из папки с exe: сначала копируется всё, исходники удаляются только после успешного копирования.
- Картинки, которые не загрузились, загружаются повторно.
- Освобождаются служебные объекты отмены, устаревшие кампании не копятся в памяти.

### Улучшено
- В блоке «Авторизация» показывается состояние плеера и время последней синхронизации реального прогресса.
- Карточки кампаний на главной стали компактнее.
- В журнале нет дублей строк прогресса и сообщения о входе.
- Выбранный вручную канал сохраняется при перезагрузке списка каналов.
- Обновлены «Первые шаги» в справке.
## v1.2.0 — 09.10.2026

### Изменено
- **Данные больше не создаются рядом с exe.** Настройки, вход, кеш картинок, профиль браузера и журнал хранятся в `%LOCALAPPDATA%\TwitchDropsMiner`. Exe можно класть куда угодно.
- Данные прежних версий, лежавшие рядом с exe (`config`, `cache`, `browser`, `log.txt`), при первом запуске переносятся автоматически, вход сохраняется.
- Портативный режим: пустой файл `portable.txt` рядом с exe — данные хранятся рядом с ним, как раньше.

## v1.1.0 — 08.10.2026

### Изменено
- **Вход только через встроенный браузер.** Убраны вход по коду активации и импорт входа из `cookies.jar` Python-версии: с этими способами Twitch не засчитывает просмотр.
- Если вход не выполнен, окно входа через браузер открывается автоматически.
- Сохранённые входы других клиентов (код активации, импорт) игнорируются, приложение попросит войти через браузер.
- Если WebView2 не запускается по другой причине (например, программу перенесли во время работы), в журнал пишется настоящая ошибка, а не «WebView2 не установлен».

Импорт **настроек** (списки приоритета и исключений) из Python-версии остался.

## v1.0.0 — 08.10.2026

Первый выпуск: порт [Twitch Drops Miner](https://github.com/DevilXD/TwitchDropsMiner) с Python/tkinter на C# / .NET 10 / WPF.

### Перенесено из оригинала
- Конечный автомат майнера: загрузка инвентаря, выбор игр по приоритету, сбор каналов, переключение, ежечасная перезагрузка, очистка каналов по времени начала и окончания кампаний.
- Пул websocket-соединений Twitch PubSub (до 8 × 50 топиков, до 199 каналов).
- GQL-запросы с ограничением частоты, повторы с экспоненциальной задержкой.
- Списки приоритета и исключений, три режима приоритета, фильтры инвентаря.
- Трей, уведомления, автозапуск, прокси, тёмная тема, 21 язык интерфейса, параметры командной строки и коды выхода.

### Новое
- Интерфейс на WPF без подтормаживаний: виртуализированные списки, фоновая загрузка картинок.
- Главная вкладка с кампаниями и прогрессом каждого дропа.
- **Вход через встроенный браузер** (Microsoft Edge WebView2) и получение integrity-токена.
- **Просмотр настоящим плеером Twitch в скрытом окне** (без звука, 160p). С осени 2026 Twitch засчитывает время только так.
- **Реальный прогресс со страницы инвентаря Twitch**: API его больше не отдаёт.
- Запасной публичный каталог кампаний для входа по коду.
- Импорт настроек и входа из Python-версии.
- Токен хранится зашифрованным (DPAPI).
- Изменения приоритета, исключений и режима применяются автоматически.
- После сбоя майнер сам перезапускается через минуту.
- Режим «закрытие окна сворачивает в трей», повторный запуск exe открывает уже запущенное окно.
